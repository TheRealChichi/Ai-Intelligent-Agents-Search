# AI Intelligent Agents – Search Problems (Python)

This repository contains implementations of intelligent agents designed to solve classic search problems using Python. The projects were developed as part of the **EEE-5513 Software Development for AI** course.

## Projects

### 1. Homework 1 – Basic Vacuum Cleaner (BFS)
- Implements a simple vacuum cleaner agent using Breadth-First Search.
- Dynamically adapts to user-defined room setups.

### 2. Homework 2 – Vacuum Cleaner (BFS + UCS)
- Expands to Uniform-Cost Search.
- Shows path cost optimization and search tree traversal.

### 3. Homework 3 – Romania Route Planner (A* Search)
- Solves the Arad-to-Bucharest problem using A*.
- Uses city-to-city distances and heuristic estimates.

### 4. Homework 4 – Erratic Vacuum World (AND-OR Search)
- Models nondeterministic agent behavior.
- Implements an AND-OR search tree for uncertainty handling.
